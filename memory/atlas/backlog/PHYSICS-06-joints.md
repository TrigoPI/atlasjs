# Joints

Aucun support de joints (distance, revolute, etc.) n'existe dans le contrat `@atlasjs/inertia` ni dans son backend rapier. À concevoir si un besoin gameplay concret (grappin, chaîne, porte articulée) émerge — rapier2d-compat les expose nativement, mais rien ne les surface aujourd'hui côté AtlasJS.
