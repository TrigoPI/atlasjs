Audio system — **SHIPPED to dev on 2026-08-11** (merged by the user). The pillar that was missing after prefabs. v1 = SFX one-shots + looping music + volume (per-source & master), autoplay-unlock on first gesture + pause on tab blur. Spatial audio = V2 (backlog).

**Architecture (split façon `@atlasjs/input`):**
- **`@atlasjs/audio`** (new, pure backend, ECS-free — deps: core/assets/utils only, never nexus/gameplay): `AudioEngine` (owns the Web Audio graph + master gain + unlock/visibility; **injectable + SSR-safe**: guards `window`/`document`, ctor `new AudioEngine(ctx?, { target?, doc? })` → tests run in plain node, no jsdom), `AUDIO_ENGINE` token, `AudioClipAsset`/`AudioLoader`/`AudioClip`, `Voice`(internal)/`AudioVoice`(public interface), `AudioPlugin` (requires ASSET_MANAGER, provides AUDIO_ENGINE, registers the loader).
- **`@atlasjs/gameplay`** (ECS integration, like PlayerInput/PlayerInputSystem/InputApi): `AudioSource` (LEVEL-1 data component: clip/volume/loop/mute/playOnAwake + `command` enum + `isPlaying`, public fields), `AudioSystem` (reconciles AudioSource→voice each frame, stage `update`/`Late`, keyed `Map<AudioSource, AudioVoice>`), `AudioApi` (ScriptService façade `playOneShot`/`masterVolume`/`muted`). `GameplayPlugin` **hard-requires AUDIO_ENGINE** → both the shared harness AND `determinism.test.ts` provide a `Provide("stub-audio", AUDIO_ENGINE, FakeAudioEngine)`. Any external gameplay consumer must now install AudioPlugin (or a stub).

**Docs:** spec `memory/atlas/gameplay/audio.md`, plan `docs/audio-system-plan.md`, backlog "Audio" section.

**V1.1 « variation » (2026-08-11, implémenté + browser-vérifié, stagé sur `dev` en attente du commit user):** ajoute un **bouton `pitch` appliqué** (→ `AudioBufferSourceNode.playbackRate`, tape-style hauteur+vitesse couplées) au même niveau que `volume` — `AudioEngine.createVoice/playOneShot` + `Voice.apply(volume,muted,pitch)` live + type `PlaybackParams {volume?;pitch?}` ; **breaking** `playOneShot(clip, volume?)` → `playOneShot(clip, params?)` ; `AudioSource.pitch` (champ plat défaut 1, **pas** de range natif) + `AudioSystem` le propage à la création ET live ; `AudioApi.playOneShot(params?)`. **Décision d'archi (user):** le random reste **contrôlé en code de jeu** (prefab/script), pas natif au composant — 2 helpers purs `randomRange(min,max,rng=Math.random)` + `pickRandom(items,rng=Math.random)` (throw sur vide) dans **`@atlasjs/utils`** (nouveau module `random`, seule frontière de non-déterminisme ; `Math.random` interdit dans audio/math/gameplay). Demo dino-brawl : prefab footstep `pickRandom([grassSound])` + `randomRange(0.9,1.1)` pitch + `randomRange(0.05,0.1)` volume ; browser-verify = 8 foulées → 8 pitchs distincts tous dans [0.9,1.1]. Spec `memory/atlas/gameplay/audio-variation.md`, plan `docs/audio-variation-plan.md`. V2 backlog inchangé (spatial/pan, bus/ducking, crossfade, pooling). **Trou de plan corrigé en cours:** mon grep initial de callers `playOneShot` a raté les fichiers de test → `packages/gameplay/test/audio-api.test.ts` (fake local + call site) a dû être migré vers `PlaybackParams` (scope étendu en cours de route).

**Gotchas learned:** dino-brawl references assets via Vite `@assets/*` imports centralized in `ResourcesPath.ts` (NOT hardcoded `/assets/...`) — audio wired as `import Music from "@assets/audio/music.wav"` → `ResourcesPath.Audio.Music` → `new AudioClipAsset(...)` (see [[vite-type-only-imports]] for the `import type` split in ArenaScene). A **placeholder `apps/dino-brawl/assets/audio/music.wav`** (synthesized 3s seamless loop, 132KB) was committed — the user may swap it for real music. Browser-verified: click → resume() → ctx "running" → clock advancing → 1 source.start.

**Review fix (opus final review):** `AudioEngine.unlock()` originally removed listeners + set `unlocked` BEFORE `await resume()` → a transient resume-reject left the session silent with no retry. Fixed to resume-first (return on catch, keeping listeners), set `unlocked`/remove listeners only after success. Also added `AudioLoader` `response.ok` guard. Delivered subagent-driven, one task at a time per [[execution-cadence-preference]], like [[prefab-instantiation-feature]].
