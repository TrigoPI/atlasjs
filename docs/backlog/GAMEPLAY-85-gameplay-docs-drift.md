# Cinq docs gameplay en dérive et un index qui les déclare tous conformes

Vérification doc par doc contre le code : `docs/README.md:31-45` déclare « implémenté » les 15 docs de `docs/gameplay/`, **5 sont en dérive**. Par ordre de danger : (1) `gameplay-redesign.md` §2 (`:89-118`) / §3 (`:120-148`) / §6 (`:195-217`) décrit encore une façade-classe **avec cache** (`private cached: Transform2D | null`) et un `ScriptComponentRegistry` invalidé par `onRemove` — décision inversée depuis au profit d'un token apatride re-résolu à chaque accès ; les fichiers cités (`Transform2DComponent.ts`, `RigidBody2DComponent.ts`, `ScriptComponentRegistry.ts`) n'existent pas — `src/scripting/components/` ne contient que `Transform.ts` et `CharacterController.ts` — et un lecteur qui suivrait ce doc **réintroduirait le bug que la saga des tokens a éliminé**. (2) `tilemap.md:38,48,197,253` reporte comme « à faire » les sorting layers nommés et le cache `revision`, tous deux implémentés (`SortingLayers` ; `RebuildKey` dans `TileMapRenderSystem.ts:29-35`), et documente une formule de tri (`node.zIndex = renderer.sortingOrder`, `:193` et `:248`) qui n'existe plus — `zIndex`/`sortKey` ont été remplacés par `sortingLayer`/`sortPrimary`/`sortSecondary` (`src/rendering/applySortFields.ts`), et `zIndex` n'apparaît plus nulle part dans `packages/nebula/src`.

(3) `audio.md` a 4 écarts d'API : champs `command`/`isPlaying` publics (`src/components/AudioSource.ts:20-21`) là où le doc les dit privés (`:166-167,176`) ; `playOneShot(clip, volume)` (`:137,212`) devenu `(clip, params: PlaybackParams = {})` (`packages/audio/src/AudioEngine.ts:78`) ; `Voice` annoncé non exporté (`:52,151`) alors qu'`AudioVoice` est public (`packages/audio/src/index.ts:4`) ; `destroy()` annoncé stoppant les voix (`:145,258`) alors que `AudioEngine.destroy()` (`:129-141`) ne fait que retirer les listeners et `ctx.close()`.
