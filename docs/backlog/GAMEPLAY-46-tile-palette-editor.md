# Palette de tuiles / éditeur (authoring visuel)

Peindre une tilemap directement dans une grille visuelle suppose une interface d'édition complète, qui n'existe pas et n'a pas de brique de départ : ni `packages/editor` (supprimé du dépôt) ni équivalent ne fournit de canevas à consommer. Le sujet reste entièrement à concevoir.
